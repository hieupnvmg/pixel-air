# README media

These files show the actual launcher, not design mockups.

| Asset | Source |
| --- | --- |
| `banner.svg` | Original vector banner using the project's own icon and colors. |
| `home.png` | Version 0.23 Home with two folders and a notification dot on Messages. |
| `drawer.png` | Version 0.23 app drawer with Frequent apps and category backgrounds. |
| `folder.png` | Version 0.23 Google folder opened as an icon grid panel. |
| `search.png` | Version 0.23 drawer search for "ca": apps, an app shortcut, settings pages and the web row. |
| `themed-icons.png` | Version 0.23 Home with themed icons on. Camera and Files have no monochrome layer and keep their own icons. |
| `settings.png` | Version 0.23 settings: icon packs, themed icons, notification dots and motion. |
| `drawer-collapsed.png` | Version 0.23 drawer with the Tools and Media groups collapsed. |
| `drawer-horizontal.png` | Version 0.23 optional horizontal drawer, Frequent page. |
| `unlock.gif` | Version 0.23 swipe-up unlock to Home, cut from an emulator screen recording. Played at normal speed, 25 fps, with the final frame held for the loop. |

All captures come from the Android 17 emulator (Medium Phone, 1080×2400). Screenshots are scaled to 540×1200 without changing UI content. The GIF has a still-image alternative for readers who request reduced motion in their browser.

Third-party app icons and the emulator wallpaper appear as part of the captured Android UI; their respective owners retain rights to that artwork. They are not supplied as standalone launcher assets. See the repository's NOTICE file.
