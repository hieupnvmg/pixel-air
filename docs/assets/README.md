# README media

These files show the actual launcher, not design mockups.

| Asset | Source |
| --- | --- |
| `banner.svg` | Original vector banner using the project's own icon and colors. |
| `home.png` | Final Home frame from the version 0.11 emulator recording. |
| `drawer.png` | English app drawer capture from version 0.13, showing expanded groups and jump chips. |
| `settings.png` | English settings capture from version 0.10; the shown controls remain available in 0.11. |
| `unlock.gif` | Shortened loop from the version 0.11 emulator recording, resized and palette-optimized for the README. Playback speed is unchanged; the first and final frames are held briefly for the loop. |

The full recording is attached to the v0.11 GitHub release. Static screenshots are resized proportionally, without changing UI content. The GIF has a still-image alternative for readers who request reduced motion in their browser.

Third-party app icons and the emulator wallpaper appear as part of the captured Android UI; their respective owners retain rights to that artwork. They are not supplied as standalone launcher assets. See the repository's NOTICE file.

`drawer-collapsed.png`: version 0.13 emulator capture with the Media group collapsed by tapping its header.

`drawer-horizontal.png`: version 0.14 emulator capture of the optional horizontal drawer, Media page.
